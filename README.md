A revisão prepara vocês para a **avaliação escrita**, que cobra os mesmos conteúdos.

## 🎯 O que é cobrado

O foco não é decorar, e sim **entender o que o algoritmo faz**. Os conteúdos são:

| Assunto | Métodos e comandos |
|---|---|
| Leitura e conversão de valores | `.value`, `Number()`, `parseInt()`, `parseFloat()`, `isNaN()` |
| Tratamento de texto | `.trim()`, `.split()`, `.join()`, `.replace()`, `.toFixed()` |
| Arrays | `.push()`, `.sort()`, `.splice()`, `.slice()`, `.forEach()`, `.map()`, `.filter()` |
| Matemática | `Math.max()`, `Math.floor()`, `Math.random()` |
| Lógica | `if / else if / else`, laço `for`, validação com `return`, busca do maior valor |

A primeira página do PDF tem um **quadro-resumo** explicando cada método. Comece por ele.

## ✏️ Como resolver

1. **Faça o "teste de mesa".** Em uma folha, anote o valor de cada variável linha por linha, como se você fosse o computador executando o código.
2. **Preste atenção aos tipos.** O que vem de `.value` é sempre **texto** (string). Lembre o que acontece com `"10" + "5"`.
3. **Leia os comentários do código** (`// ...`). Eles dizem o que o usuário digitou.
4. **Desconfie das alternativas "quase certas".** Muitas trocam só um detalhe, como ponto por vírgula, índice 0 por 1 ou ordem crescente por decrescente.
5. **Na dúvida, teste!** Abra o navegador, aperte `F12`, vá na aba **Console**, cole o trecho e veja o resultado. Depois tente entender *por que* deu aquele resultado.

## 🤖 Sobre o uso de IA

Vocês usaram IA para construir os projetos, e tudo bem. Mas na avaliação escrita **não haverá IA, nem consulta**. Use esta revisão para ter certeza de que você entende cada linha do código que entregou. Se não souber explicar um trecho, estude esse trecho.
